# Expense & Finance Tracker

A full-stack MERN application for managing personal income, expenses, budgets, and financial insights.

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Redux Toolkit
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt

### Tools
- Git
- GitHub
- Postman
